# ui/panels — nền panel (9-slice)
| File | Dùng cho |
|---|---|
| `panel.png` | nền CHUNG: Status, Skills, Battle, VIP, Chat, Character, Spells, NPC, Depot, House, Party, Auto, Bản đồ... + mọi PanelContainer chưa tự đặt style |

- `content=` = lề chữ bên trong (mặc định bằng margin).
