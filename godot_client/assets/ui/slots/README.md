# ui/slots — ô hotbar (F1..F12)
Tên: `slot_<trạng thái>.png` với trạng thái `normal` `hover` `pressed`. **Chỉ cần `slot_normal.png`.**
Muốn khác nhau theo loại ô: `slot_item_normal.png` (ô gán item/pot/rune), `slot_spell_normal.png` (ô gán spell), `slot_empty_normal.png` (ô trống) — thiếu thì dùng `slot_normal`.
Kích thước ô hiện tại 38x38. Lề 9-slice: mục `[slot]` trong `skin.cfg`.
