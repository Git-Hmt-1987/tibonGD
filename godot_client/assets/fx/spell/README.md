# fx/spell — hiệu ứng RIÊNG TỪNG SPELL (ưu tiên cao nhất)
Tên theo **id spell** (xem `tibia_py/spell_data/spells.json`):
- `<id>.png` — hiệu ứng trên từng ô bị ảnh hưởng (vùng đánh)
- `<id>_shot.png` — đạn bay (vẽ hướng →)
- `<id>_cast.png` — hiệu ứng ngay trên người cast (dành cho sau)
Hiện chỉ spell do CHÍNH MÌNH cast mới biết id (gói `fx` của server chưa gửi id spell) — xem `UI_PLAN.md` mục "Yêu cầu server".
Định dạng dải khung: xem `assets/README.md`.
